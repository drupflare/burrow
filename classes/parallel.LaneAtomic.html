    Class LaneAtomic

    A number shared by every lane, with the operations of Atomics.

    Every op from inside a slice carries that slice's (job, slice) identity, so a hedged or retried slice that repeats an op is answered what the first run got instead of applying it again. From the caller, where nothing is hedged, ops apply as sent.

    Example

    const hits = pool.atomic('hits');
    await hits.add(1);
