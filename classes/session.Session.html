    Class Session

    A resident interpreter that keeps its state between evaluations.

    This is the REPL and CLI shape: globals, loaded classes and the filesystem all survive from one eval to the next, because the interpreter is booted once and the session holds its lease for its whole lifetime. That lease is also what stops the budget evicting the interpreter mid-conversation.

    Example

    await using sh = await burrow.session('php');

    await sh.evalText('<?php $composer = json_decode(file_get_contents("composer.json"), true);');
    const name = await sh.evalText('<?php echo $composer["name"];');
