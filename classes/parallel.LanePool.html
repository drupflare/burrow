    Class LanePool

    A pool of lanes: one job's slices spread across Durable Objects of one class, each on its own execution context.

    Measured on a deployed Worker: one job split 16 ways ran 6.46x faster, and 8 lanes held 768 MiB for one job where a single isolate refuses 192 MiB. Lanes share no memory; slices exchange bytes.

    Example

    const pool = new LanePool(env.BURROW_LANES, { size: 16 });
    const sums = await pool.map({ guest: bytes, fn: 'fnv' }, chunks);
